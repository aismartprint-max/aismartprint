AISmartPrint website starter
=============================
Files:
- index.html : website
- style.css  : responsive blue/white design
- script.js  : product selection and estimated-price calculator

Important:
1. The rates in script.js are SAMPLE/PLACEHOLDER rates. Replace them with your actual printing prices.
2. Add your merchant UPI QR image and UPI ID before going live.
3. WhatsApp number is configured as 9177361421.
4. This is a front-end starter. Real card/UPI payment verification, order database, admin panel and secure file storage require a backend/payment gateway integration.
